# house-3d-plan
Interactive 3D model of a 4-bedroom house (three.js viewer)

## Pages
- [3D plan](https://blayxi.github.io/house-3d-plan/) (`index.html`)
- [Exterior variants](https://blayxi.github.io/house-3d-plan/variants.html) (`variants.html`)
- [Walk-through](https://blayxi.github.io/house-3d-plan/walk.html) (`walk.html`)
- [Four-bedroom eye-level walk-through](https://blayxi.github.io/house-3d-plan/house-4bed-walkthrough.html) (`house-4bed-walkthrough.html`): same floor plan, limestone portico and fountain court, flat roof terrace with sunroof, pergola and bar. Opens at eye level; hold the on-screen arrows or use W A S D / arrow keys, drag to look around.
